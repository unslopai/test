# shop

Small shop monorepo.

- `web/` – Next.js storefront (app router)
- `services/auth/` – Express auth API
- `services/upload/` – Flask upload service
- `services/catalog/` – Go catalog service
- `services/payments/` – Express payment webhooks
- `services/fetcher/` – Flask link preview service
- `tools/` – Python maintenance scripts
- `db/schema.sql` – Postgres schema
